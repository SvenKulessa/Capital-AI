# CADS Standalone Repository Export Plan

Status: **BLOCKED UNTIL CAPITAL-AI PACKAGE ACCEPTANCE**

Target repository: `<TARGET_GITHUB_ORG>/CADS`

The dedicated repository is created only from an exact accepted Capital-AI source identity.

## Exported product scope

The export includes:

- CADS benchmark core and tests;
- CADS Marketplace runtime and tests;
- CADS observability;
- bounded HTTP-security helpers required by the runtime;
- Marketplace registration/plan manifests;
- Supabase Marketplace entitlement migration;
- CADS package/B2B benchmark harnesses;
- export provenance tooling;
- CADS product/license/third-party notices;
- security, privacy, support, B2B terms and installation documentation.

## Explicitly excluded

- MARKET provider adapters, provider credentials and market-data rights;
- NATS/Valkey infrastructure not required by the standalone CADS package;
- JaJa/Chat Buddy assets;
- Social Media Engine;
- unrelated Capital-AI web UI;
- SEO/GROWTH code;
- owner/admin control-center code;
- secrets and runtime credential values;
- unrelated third-party dependency inventories.

## Export identity

The source of truth is generated by:

`npm run evidence:cads-export`

The resulting `CAPITAL_AI_CADS_EXPORT_PROVENANCE@1` artifact binds:

- Capital-AI source commit;
- source path;
- Git blob SHA;
- SHA-256;
- byte size.

The standalone repository must reproduce these hashes for unchanged exported files or document an
explicit transformation mapping where paths/scaffolding are changed.

## Standalone revalidation

After export, do **not** inherit the Capital-AI PASS blindly. The new repository must independently
run:

1. functional CADS tests;
2. package microbenchmark;
3. B2B lifecycle benchmark;
4. provenance verification;
5. dedicated container/image build;
6. SBOM;
7. vulnerability + secret scan;
8. runtime license inventory;
9. non-root/read-only/cap-drop runtime smoke;
10. Marketplace installation/configuration smoke.

Only the exact standalone artifact that passes those checks can become the Marketplace release
candidate.
