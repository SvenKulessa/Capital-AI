## Architecture A
Kostenlose, kommerziell zulässige Standard-APIs und OSS sind Priorität 1. Free Tier ist keine Kostenfreigabe. Billable-overage Adapter stoppen lokal vor bekannten kostenlosen Grenzen; automatische Quota-Erhöhung, Paid-Fallbacks und Provider-Upgrades sind verboten. Generative AI ist Capability, nicht Daten-, Rechts- oder Publication-Authority.

## Zero-Cost Gate
Kanonisch: `src/contracts/zeroCostApiThresholds.ts`.
```text
request -> capability/right check -> usage ledger -> threshold -> provider quota readback -> execution -> evidence reconciliation
```

## GraphRAG
Microsoft GraphRAG 3.2.x ist als isolierte Research-Engine hinter Adapter/Sidecar vorgesehen. DRIFT ist Default; Local/Global/Basic sind Challenger. Claims binden Source, Dataset, Observation Time, Model/Calculation Version und Validation Evidence. Agenten dürfen recherchieren und Vorschläge erzeugen, aber keine Rechtskonformität attestieren, Paid Services aktivieren, Trades/Token-Issuance autorisieren oder Public Claims freigeben.

## Wissenschaftliche Modelle
Je Assetklasse/Unterklasse werden Literaturevidence, point-in-time data, Look-ahead-/Survivorship-Kontrollen, Walk-forward/Out-of-sample Validation, Unsicherheit/Kalibrierung und Replay verlangt. Equity, Fixed Income, FX, Commodities, Indices, Crypto, Stablecoins und DeFi/LST erhalten getrennte Modellfamilien statt eines universellen „besten“ Modells.

## Blockchain/Tokenomics Benchmark
Google Blockchain Analytics/BigQuery bleibt Read-only Challenger. Vergleich: Subsquid, The Graph graph-node, Ponder; Blockscout ist wegen aktueller kommerzieller Lizenzgrenze nicht unrestricted free-commercial Prio 1. Der Bericht wird im owner-only Control Center projiziert.

## Privacy-/Utility-Konzept
