## Credential storage

In SvenKulessa/Capital-AI: Settings > Secrets and variables > Actions > New repository secret.
Name: IONOS_API_KEY. Value: <public-prefix>.<secret>, one line, no whitespace or header label.
The IONOS Hosting DNS API uses X-API-Key with this value. Do not use an IONOS Cloud API token.
A GitHub secret cannot be read back by the assistant; only a deliberately configured workflow can consume it.
Do not put this credential in the public frontend, source, Render runtime or a normal Actions variable.

## Migration sequence

1. Deploy the MTA-STS endpoint and verify the new onrender.com address returns 200 text/plain with the exact policy below. Check image digest, security gates and headers. Complete OIDC setup before sending production users to the new login.
2. Inventory current IONOS A/AAAA/CNAME values and Render custom domain bindings for all three exact hostnames; save rollback values. Add the domains to Capital-AI using the Render dashboard/API. If a hostname is already bound to Finance, coordinate its removal and addition in a short migration window. DNS alone does not move Render bindings. Use the DNS instructions generated by Render for this specific service; do not guess IPs. Do not remove Finance before rollback is verified.
3. Update only web address records at these three hostnames. Preserve MX, TXT, SPF, DKIM, DMARC, TLS reporting and _mta-sts TXT records. Inspect IONOS managed-service conflicts before any mutation; do not use bulk zone replacement. Root and www redirect behavior must be checked so the selected PUBLIC_APP_ORIGIN has a stable canonical origin.
4. Verify DNS and valid TLS for all three hostnames, health/security headers, OIDC login/session/logout and https://mta-sts.capital-ai.online/.well-known/mta-sts.txt. Record observed commit and immutable image digest separately; a Render source commit does not prove GHCR digest provenance.

Production auth origin will be https://capital-ai.online if this is the chosen canonical origin.
Register exact OIDC callback https://capital-ai.online/api/auth/callback and post-logout https://capital-ai.online/login before switching PUBLIC_APP_ORIGIN. Existing code implements local session logout only, not provider logout.

## Current completion boundary

This PR prepares the policy endpoint and migration runbook. It does not contain an IONOS mutation workflow, change DNS, transfer Render custom domains, change OIDC credentials or trigger deployment. The Render connector currently exposes no custom-domain operation. The credential and live DNS inventory are prerequisites for a constrained DNS workflow.
