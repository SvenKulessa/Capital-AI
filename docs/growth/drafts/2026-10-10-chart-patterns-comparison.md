# Bull Flag oder aufsteigendes Dreieck?

Eine **Bull Flag** besteht aus einem deutlichen Aufwärtsimpuls und einer anschließenden, oft leicht abwärts gerichteten Konsolidierung. Ein Schlusskurs oberhalb des Kanals kann eine Fortsetzungsthese stützen. Ein Rückfall in den Kanal oder unter die Konsolidierung schwächt sie.

Beim **aufsteigenden Dreieck** stehen höhere Tiefs einer annähernd horizontalen Widerstandszone gegenüber. Ein Schlusskurs darüber kann eine mögliche Auflösung stützen; ein Bruch der steigenden Unterstützung kann die These entkräften. Keines der Muster garantiert eine bestimmte Kursbewegung.

Der CAPITAL-AI-Lernatlas dokumentiert 52 Lektionen mit selbst entworfenen synthetischen Chartgeometrien. Das ist Finanzbildung, keine Live-Kursdarstellung und keine produktiv verifizierte Scoring-Prognose. Ob ein konkreter Nutzer die Lektionen live öffnen kann, hängt vom Deployment und den Entitlements ab.

**Merksatz:** Muster erkennen, Bestätigung prüfen, Fehlsignal ernst nehmen.
