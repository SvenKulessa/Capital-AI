## Local use
- `npm run growth:intelligence:dry-run`: existing draft bundle includes xAcquisition, sorted X candidate IDs and canonical UTM links. GA4 campaign sessions, Supabase campaign registrations and Stripe paid subscriptions are null until actual independently authenticated campaign-level evidence exists.
- `node --import tsx scripts/growth/growth-intelligence-drafts.mjs --x-acquisition-candidate < /absolute/private/candidate.json`: JSON keys contentId (from dry-run) and editorialBody (no link or mention). Output includes reviewed-copy candidate, digest and conservative length upper bound. No text truncation; max 270 including newline and t.co URL weight 23. Restricted editorial subset, not a full twitter-text parser. The existing publisher raw-length limit remains independent; never assume this draft can be sent unchanged.
- `node --import tsx scripts/growth/growth-intelligence-drafts.mjs --x-acquisition-forecast < /absolute/private/budget.json`: required exact keys asOf, pilotStartedAt, quoteObservedAt, quoteEvidenceSha256, balanceObservedAt, balanceEvidenceSha256, spentMicroEur, reservedMicroEur, remainingCreditMicroEur, otherCostUpperBoundMicroEur, autoRechargeDisabled (true), upperBoundPerUnitMicroEur and quantities. Both operation maps require linkWrites, textWrites, postReads, ownedReads, userReads, tokenRefreshes. Quantities must include all billable resources, including one readback per write; unknown costs block. EUR upper bounds must include conservative FX, tax and other costs, independently reviewed against actual console pricing. Use integer micro-EUR (1 EUR = 1,000,000); no hardcoded tariffs. Forecast rejects over 20 EUR account-wide spend + unsettled reservations + forecast and insufficient remaining credit. Evidence quote <=24h and balance <=1h, 30-day UTC elapsed window. Neither supplied hashes nor amounts are authenticated by this offline projection. Never pass credentials or personal identifiers; local input max 16 KiB, error output sanitized.
