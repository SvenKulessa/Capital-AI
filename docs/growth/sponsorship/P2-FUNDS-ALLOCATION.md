# Sponsorship P2 — geplante Mittelverwendung

Status: **PLANUNG, KEINE COST_EVIDENCE**

Sponsoring-/Fördermittel sollen ausschließlich auf evidenzfähige Arbeitspakete abgebildet werden. Konkrete Beträge oder Quoten werden erst nach belastbarer Budgetentscheidung eingetragen.

| Kategorie | Work Packages | Nachweis bei tatsächlicher Ausgabe |
|---|---|---|
| Daten-/Provider-Evaluation | SP2-WP-01, SP2-WP-02 | Provider-/Usage-Readback + COST_EVIDENCE@1 |
| Research/Experimente | SP2-WP-03 | Experiment-/Research-Evidence + Kostenbeleg |
| Plattform-/Supply-Chain-Infrastruktur | SP2-WP-04 | Runtime-/Artifact-Readback + Kostenbeleg |
| Compliance/Evidence | SP2-WP-01, SP2-WP-05, SP2-WP-06 | License/Claim/Cost Evidence |
| Dokumentation/öffentliche Forschungsdarstellung | SP2-WP-07 | Evidence Bundle + Documentary-Projektion |

Geplante Mittel werden niemals automatisch in `COST_EVIDENCE@1` übernommen. Tatsächliche Kosten benötigen Provider, Zeitraum, Ressource, Menge/Einheit, Betrag und Beleg oder Usage-Readback.
