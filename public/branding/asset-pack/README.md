# CAPITAL-AI Branding Asset Pack

The original derivative asset pack is generated solely from public/branding/capital-ai-logo.jpg. The source SHA-256 is pinned in the generator and must match before any logo derivative is produced.

The pack contains SocialMediaEngine-aligned social formats, avatar/profile variants, banners, Google OAuth upload artwork, generic vendor application graphics, favicon/PWA formats, and raster-preserving SVG wrappers.

## Subscription, product and role badges

`public/branding/asset-pack/svg/capital-ai-badge-*.svg` contains deterministic vector badges for STARTER, PRO, ENTERPRISE, VOCABULARY, FREE USER, VAULT and OWNER. These badge SVGs are separate owner-directed assets and are not derivatives of the logo JPEG.
